TROUBLESHOOTING
───────────────
Problem: All values are identical (like 8.50 at every layer)
Solution: Check that you're using the REVISED script, not the broken causal_patching_behavioral.py
          The broken version measures loss, which is layer-invariant.
          Use causal_patching_behavioral_c_only.py instead.

Problem: L27 is not zero
Solution: Might be measurement issue or hook not removing final token from patch.
          Check make_body_patch_hook code: end = min(T_v, T_s) - 1
          This ensures final position is excluded.

Problem: No decay pattern (random values across layers)
Solution: Patch might not be propagating correctly. Check:
          - Are hooks being registered/removed correctly?
          - Is use_cache=False being set?
          - Are activations being copied correctly (detach/clone)?

Problem: Large values at L27 (> 0.1)
Solution: Suggests final token is being patched somehow.
          Debug: Print T_v, T_s, end in make_body_patch_hook
          Verify: end = min(T_v, T_s) - 1 correctly excludes position T-1
